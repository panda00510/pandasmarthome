In Singapore, the air-conditioner is probably the appliance a home uses most. What people want from a smart setup is usually simple: cool the room before they get home, adjust it once they are asleep, and switch everything off when the last person leaves. There are two main ways to get there, each with trade-offs.

## Infrared control: the easy start

Most split-system aircons in homes use an infrared remote. A smart IR controller learns or already knows those remote signals and, placed where it can see the indoor unit, sends commands from an app, a schedule or an automation.

- **Pros:** nothing on the aircon is modified, no wiring is needed, it works in rentals and it moves with you.
- **Limits:** infrared is one-way. The controller sends a command but cannot tell whether the aircon received it. If someone changes the temperature with the original remote, or the signal is blocked, the state shown in your system can drift from reality.

To close that gap, add a temperature sensor in the room, or a device that measures power draw to tell whether the aircon is running, and let your automations check the real conditions.

## Wired adapters: accurate state

Some aircon brands offer a wired or Wi-Fi adapter for the indoor unit that talks both ways: it sends commands and reads back the current mode, set temperature and running state.

- **Pros:** reliable state, unaffected by line of sight, and often more information to work with.
- **Watch out:** whether it is supported, and which adapter you need, depends on the brand and exact model. Confirm with the manufacturer or your aircon installer before fitting one, including any effect on the warranty. Some adapters only work through the manufacturer's cloud app, so check whether local control is supported before buying.

## Automations worth setting up

1. **Pre-cool on the way home:** turn on the living room aircon when you are nearly back.
2. **Sleep mode:** raise the temperature a degree or two after bedtime, or switch off at a set time.
3. **Pause when a window opens:** stop the aircon while a window or balcony door is open, and resume when it closes.
4. **Off when the room is empty:** switch off a room's aircon after no one has been there for a while.
5. **Room-by-room control:** with a multi-split system (one outdoor unit serving several indoor units), control each indoor unit separately so empty rooms stay off.

## What to check before you start

- The brand, model and remote type of each indoor unit
- Whether the IR controller can see the indoor unit directly — cabinets and decorative panels block the signal
- Sensors on the relevant doors and windows, if you want the window pause
- Wired adapters involve the indoor unit's ports and power, so leave the installation to your aircon installer or another qualified person

## Plan it with the rest of the home

Aircon automations work best alongside curtains, temperature sensors and presence sensors: closing the curtains before the afternoon sun hits means the room needs less cooling in the first place. If you are planning motorised curtains too, design them together.
