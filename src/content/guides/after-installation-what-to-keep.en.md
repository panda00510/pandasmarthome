A smart home is only finished when the household can live with it without the installer in the room. The most common problem months later is not a broken device. It is that nobody knows the password, where the settings are, or what was set up. Ask for these things at handover.

## The administrator account

The account that can change everything should belong to you.

- **Your name and your email,** not only the installer's. You should be able to add or remove other administrators.
- **Recovery details** kept somewhere safe, such as a password manager or a sealed note, and not only in a chat history.
- **Separate everyday accounts** for family members, so that daily use does not need the administrator login.

If a system only works while a company keeps its own login, that is a dependency you should know about before you sign. See [how we work](/how-it-works/).

## Written documentation

A short document is enough. It should cover:

1. **A device list,** with the room, what it does and how it connects.
2. **Network details:** the Wi-Fi names, where the router and the controller are, and any separate network used for smart devices.
3. **An automation list,** in plain words, for example "lights off and aircon off when the last person leaves".
4. **How to turn things off,** such as which switch to flip and how to use the wall switches when the system is down.

## Backups

A backup is what lets you recover after a failed update, a broken disk or a replaced controller.

- **Where it is stored,** and whether a copy is kept away from the controller itself.
- **How often it is made,** and whether it runs automatically.
- **Who can restore it,** and whether that has been tested at least once.

## Support after handover

Agree this in writing, so that nobody guesses.

- **Who to call first,** and what is covered.
- **What is not covered,** such as a device you add yourself.
- **What happens if the installer is not available.** A standard, documented system can be serviced by another competent person. A closed one cannot.

## A walkthrough with the people who will use it

The person who sets things up is not always the person who lives with them.

- **Show the household** the wall switches, the scenes and the door codes. See [scenes a household actually uses](/guides/scenes-households-actually-use/).
- **Show the helper and the children** what they need, in a language they are comfortable in. See [who gets access to what](/guides/smart-home-helpers-kids-guests-access/).
- **Show how it behaves without internet.** See [what still works without internet](/guides/smart-home-without-internet/).

## Common questions

### Should the installer keep the administrator login?

You should hold it. An installer can keep a separate account for support if you agree to that, and you can remove it later.

### How long should the documentation be?

A few pages are enough. If it cannot be read in ten minutes, nobody will use it.

### Do I need to test the backup?

Yes, once. A backup that has never been restored is an assumption.

### What if I change the router?

Update the network details in your documentation, and check that the controller and devices reconnect. Ask whoever installed the system to help if they do not.

## A simple way to start

Before handover, write down the five things you want to be able to do without help: turn everything off, add a guest code, check a sensor, restore a backup and call for support. Ask to be shown each one.
