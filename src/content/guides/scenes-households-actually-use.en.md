A scene is one action that changes several things at once. The best ones replace a routine the household already does by hand. If nobody would miss a scene when it is gone, it is not worth building.

## Leaving the house

The most used scene in most homes.

- **What it does:** turns off lights and aircon, closes curtains if you want that, and checks that the door is locked.
- **How to trigger it:** a button by the door. A phone should be an extra, not the only way.
- **Keep in mind:** decide what the scene must not touch, such as a fridge, the router or a dehumidifier.

## Going to bed

- **What it does:** turns off the main lights, leaves a dim path to the bathroom, and sets the aircon to the night setting.
- **How to trigger it:** a button by the bed, or a timer for a fixed time with an easy way to cancel it.
- **Keep in mind:** if someone gets up in the night, a low light along the route matters more than any automation. See [a smart home for elderly parents](/guides/smart-home-for-elderly-parents/).

## Guests

- **What it does:** a comfortable level of lights and aircon in the living room, and a temporary door code if you use a keyless lock.
- **How to trigger it:** a button, or the wall switches that already work.
- **Keep in mind:** a guest should never need an app. See [who gets access to what](/guides/smart-home-helpers-kids-guests-access/).

## Movie night

- **What it does:** dims the lights, closes the curtains and brings the aircon to a comfortable level.
- **How to trigger it:** a button near the sofa.
- **Keep in mind:** this is the scene people show off, but it is the one they use least. Build it after the first three.

## How to build scenes that last

1. **One trigger per scene,** with a label in the language the household reads.
2. **A physical button first,** and the app second. See [controls for the whole household](/solutions/home-control/).
3. **Always allow a manual override.** If someone turns a light on by hand, the system should not turn it off a second later.
4. **Review after a few weeks.** Remove what is not used and adjust what is.
5. **Write them down** in your handover notes. See [what you should keep after installation](/guides/after-installation-what-to-keep/).

## Common questions

### Do scenes need the internet?

Not if they run on a controller in your home. See [what still works without internet](/guides/smart-home-without-internet/).

### How many scenes do I need?

Most households settle on three to five. More than that, people stop remembering which button does what.

### Can the aircon scene save energy?

It can help if the aircon is switched off when nobody is home. See [where the electricity goes](/guides/reduce-aircon-electricity-smart-home/).

### What if the system is down?

Wall switches should still work as normal switches, so the lights never depend on the scene.

## A simple way to start

Pick the one routine you do by hand every day, usually leaving the house, and build only that. Add the others once it has been used for a few weeks.
