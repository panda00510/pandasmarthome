智能设备并不是都用同一种方式“说话”。设备用哪种无线连接，决定了电池能用多久、能加多少个，以及家里需要什么来运行它。弄清楚差别，能少买几件不合适的东西。

## Wi-Fi

Wi-Fi 就是手机和电脑已经在用的那种连接。

- **适合：** 摄像头、音箱、电视盒子，以及所有数据量大的设备。
- **要留意：** 每个设备都是路由器上的一个客户端。几十个小型 Wi-Fi 设备，可能会把原本带手机绰绰有余的路由器挤满。
- **电池设备** 用 Wi-Fi 往往更费电，所以厂家通常会为它们选别的连接方式。

## Zigbee

Zigbee 是为小型设备设计的低功耗 Mesh 连接。

- **适合：** 门磁、温度传感器、按键、智能开关和灯泡。
- **原理：** 接市电的设备可以帮忙转发信息，所以家越大，加的设备越多，覆盖反而越好。电池设备通常不转发。
- **需要什么：** 一个支持 Zigbee 的网关或控制器。普通路由器不能直接运行它。
- **要留意：** Zigbee 和 Wi-Fi 共用 2.4 GHz 频段，选信道时要避开你最忙的 Wi-Fi 信道。

## Thread

Thread 也是低功耗 Mesh，不少较新的 Matter 设备用它。可以看 [Matter 是什么](/zh/guides/what-is-matter/)。

- **适合：** 电池传感器、门锁，以及其他支持 Matter 的小型设备。
- **需要什么：** 一台 Thread 边界路由器。有些音箱、电视盒子和网关已内置。买 Thread 设备之前先确认。

## 蓝牙

蓝牙常见于门锁和小型设备，用于设置和近距离控制。

- **适合：** 第一次连接，以及短距离控制。
- **要留意：** 距离短，只靠蓝牙的门锁，你不在家时可能连不上。可以看[智能门锁指南](/zh/guides/smart-door-lock-guide/)。

## 你还可能见到的其他连接

有些设备用别的 sub-GHz 连接，或厂家自己的射频。买之前先确认设备需要什么，以及它能不能和你打算用的控制器配合。

## 怎么选

1. **先定控制器。** 先决定由什么来管整个家，再买它能对话的设备。
2. **控制器放在中间位置，** 别塞在角落的柜子里。
3. **先用接市电的 Zigbee 或 Thread 设备** 搭好网络，再加电池设备。
4. **Wi-Fi 留给数据量大的设备。** 可以看[智能家居的 Wi-Fi](/zh/guides/wifi-for-smart-home/)。
5. **尽量留几个有线接口，** 比如给控制器拉一根网线。

## 常见问题

### 三种我都需要吗？

不需要。很多家庭一种低功耗连接管传感器和开关，再加 Wi-Fi 管其余的，就够了。

### Zigbee 会拖慢我的 Wi-Fi 吗？

信道重叠时可能互相干扰。把 Zigbee 的信道选在离主要 Wi-Fi 信道远一点的地方，通常就能避开。

### Matter 会取代 Zigbee 吗？

Matter 规定的是设备之间怎么沟通，它可以跑在 Wi-Fi 或 Thread 上。已有的 Zigbee 设备仍然有用，有些控制器还能把它们桥接过去。

### 租房的人能用吗？

可以。大多数是电池或插电设备。可以看[租房也能装智能家居吗](/zh/guides/smart-home-for-renters/)。

## 一个简单的起步方法

写下每个房间想要的设备，标出哪些是小型电池设备，哪些数据量大。这就能告诉你需要哪种连接。
