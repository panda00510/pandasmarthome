# 2026-11-22 全站文案梳理：标题、卖点、去空话、每页的下一步

## 原则

- **只改说法，不加事实。** 每一句新文案都来自站上已经写明的内容：
  - 断网照常用、系统本身不收月费：首页常见问题。
  - 交付管理员账号和设备清单：“你会收到什么”区块。
  - 分阶段加装：住宅类型卡片。
  - 插上就能用：产品页要点。
- **没有加**客户、评价、案例、统计数字、价格或回复时限。
- **「待站长处理」里需要确认的说法一律没动**，例如“支持安排”、参考起价、托管“按项目评估”。
- **卖点写成客户能得到什么**：
  - 写“一个 App 管所有品牌”，不写“开放式系统”。
  - 写“买设备前先看到书面清单”，不写“流程清晰可预期”。
- **删掉自说自话**，比如“不加修饰地回答”和“内容都来自我们自己的页面”。这类话只描述文案本身，不给读者任何信息。
