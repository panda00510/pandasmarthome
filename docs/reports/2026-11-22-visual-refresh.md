# 2026-11-22 视觉改版：设计系统统一、首页 hero、卡片、导航页脚、图片

**后续说明（2026-11-22 晚）：** 本文记录的是当时仍在线上的深色 3D 样板间视觉方向。当晚已由 Gemini 的 “Tropical Monograph”（暖色石灰石纸面、植物绿、黄铜、衬线标题）替换为当前设计，见 [2026-11-22-gemini-tropical-monograph.md](2026-11-22-gemini-tropical-monograph.md)。下文仍是该次改版当时的记录。

截图在 [redesign-2026-11-22/](redesign-2026-11-22/)：

| 文件 | 内容 |
|---|---|
| `before-{desktop,mobile}-{hero,full}.webp` | 改版前。部署前从线上 smartpanda.sg 截取 |
| `after-{desktop,mobile}-{hero,full}.webp` | 改版后。部署后从线上截取 |

- 桌面宽 1440，手机宽 390（2 倍像素密度）。
- `hero` 是第一屏，`full` 是整页（已缩小）。
- 部署前，也在本地开发服务器上截过改版后的图做对比，没有入库。本地没有配置联系方式，表单区和线上不一样。

## 原则

- 现有的设计令牌（色板、圆角、阴影、按钮）已经成体系，所以这次**收拢和补齐**，没有推倒重来。
- 不加任何新照片、客户、评价或数字。
- 首页 hero 新加的标签只写平台区块已有的“我们支持的协议”：Zigbee、Thread、Matter。

## 1. 设计系统（`src/index.css`）

- **标题字号**：新增三档。原来散落在各组件里的六种一次性字号，统一成这三档：

  | 类 | 用途 | 字号 |
  |---|---|---|
  | `.title-display` | 页面和区块标题，`SectionHeading` 用它 | 32 → 44 → 56px |
  | `.title-section` | 页内小节 | 28 → 36px |
  | `.title-card` | 卡片标题 | 17px |

  中文页的字距单独放宽。
- **眉标**：区块级的 `p.eyebrow` 由 CSS 自动画出短横线。
  - 原来 13 处手写的横线 `<span>` 删掉了。
  - 原来 4 处没有横线的区块眉标，现在和其他区块一致。
  - 卡片里的 `span.eyebrow` 不带横线。
- **新增三个共享类**：
  - `.icon-tile`：卡片图标方块，统一成 44px 一种尺寸。原来有 8 处，分 44、48px 两种。所在的卡片链接悬停时，图标填充为品牌绿。
  - `.link-more`：“了解更多 →”，悬停时箭头右移。替换了 12 处写法不一的链接。
  - `.art-stage`：产品插图背后的浅绿渐变和点阵底。

## 2. 首页 hero

- **手机**：原来手机上隐藏了交互面板，现在放在按钮下面，第一屏仍然是标题和“预约咨询”按钮。只渲染一个面板，没有为手机另复制一份，避免重复内容。
- **桌面**：
  - 面板放大到 110%，两栏比例调整，左右间距更紧凑。
  - 面板角上挂一个玻璃标签：中文“支持 Zigbee · Thread · Matter”，英文 “Works with Zigbee · Thread · Matter”。
- **“Panda 其他业务”这一行**：在手机上把标签单独放一行，三个入口不再和标签挤在一起换行。

## 3. 产品卡和场景卡

- **产品页设备卡**：插图背景从平涂的浅绿，改成带点阵的柔光底（`.art-stage`）。
- **首页和 `/homes/` 的住宅照片卡**：悬停时照片在卡片内轻微放大，开启“减少动态效果”时不放大。卡片标题统一用 `.title-card`。
- **`/solutions/` 的方案卡和场景卡、首页方案卡**：图标、标题、“了解更多”都统一用上面的共享类。

## 4. 导航和页脚

- **页眉**：
  - “产品”“定制”两个下拉按钮原来固定显示为绿色加粗，看起来像当前页。现在和其他链接同色同字重，只有当前页或展开时高亮。
  - 深色页眉上的当前页也会高亮。
  - 手机菜单里，当前页有底色。分组标题从绿色改为中性灰。
- **页脚**：原来 15 个链接不分组。现在按页眉的分组排成四栏：
  - 智能家居：服务、住宅类型、流程、3D 样板间、需求小问卷。
  - 产品：信息屏、桌面设备、安装的设备。
  - 定制：硬件、软件。
  - 资料与公司：指南、常见问题、术语表、对比、关于、询价。

  联系方式移到品牌介绍下面。没有删掉任何链接，只新增了“安装的设备”一项，指向产品页的智能家居设备区。

## 5. 加载速度

- **住宅照片**：新增 480px 宽的 WebP。`scripts/make-photos.mjs` 的尺寸表同步加上了 480。
  - 桌面 1 倍屏的 280px 卡片不再下载 800px 的图。
  - 用 1600px 图缩放生成，没有压缩原有的几档，避免二次压缩损失画质。
- **联系区卧室照片**：原来是一张 1280px、88 KB 的图，实际显示约 430px 宽。现在改为 640 / 960 两档，用 `srcset` 按需加载。
- **英文页预加载 Inter 拉丁字体**：由 `scripts/prerender.mjs` 加入，字体不用等 CSS 下载完才开始下载。中文页先用系统中文字体，不预加载。
- **首页图片下载量**（用 Playwright 滚动整页，累计图片响应体积）：

  | 场景 | 改版前（线上） | 改版后（本地） |
  |---|---|---|
  | 桌面 1440，1 倍屏 | 304 KB | 130 KB（−57%） |
  | 手机 390，3 倍屏 | 216 KB | 217 KB |

  手机 3 倍屏需要高分辨率图，所以下载量基本不变，这符合预期。
