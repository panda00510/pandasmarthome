## 素材：只用我们有权使用的

- **样板间渲染图**：新增的画面全部来自我们自己的 3D 样板间（`showroom/`）。用 `scripts/capture-showroom-stills.mjs` 截取自动演示的五个场景，可以重复生成：
  - 傍晚的全屋
  - 开灯的客厅
  - 观影模式
  - 睡眠模式下的卧室
  - 离家模式的全屋

  另外从离家全景里截出大门和门禁那一块。
- **都标成渲染图**：每张图都带“3D 样板间渲染 / 3D showroom render”标签，alt 文字也写明是渲染图，不会被当成真实的安装照片。
- **没有渲染图的三项服务**（空调、控制方式、能耗）：用自绘的线稿卡片 `CardArt.tsx`。线稿里没有读数，也没有任何数字。
- 没有新增照片、客户、评价、案例或统计数字。
- 首屏的“支持 Zigbee · Thread · Matter”标签，沿用平台区块已有的说法。

## 改了什么

1. **首屏**
   - 右侧换成样板间客厅傍晚开灯的渲染图，用大圆角画框加阴影。交互控制面板叠在渲染图的左下角，协议标签钉在画框右上角。
   - 背景在渲染图后面加了一层暖光，配合原有的绿光和网格，层次和色彩更丰富。暖色只用在灯光场景里，符合设计约定。
   - 手机上，渲染图放在按钮下方，控制面板叠在渲染图底边，第一屏仍然是标题和“预约咨询”按钮。
   - 中文标题在桌面端单独调了字号，保证两行完整，不在词中间断行。
2. **行动按钮更明确**
   - 首屏两个按钮改成“预约咨询”和“体验 3D 样板间”。原来的第二个按钮是“查看安装内容”。
   - 按钮下面加一行说明：“中英文均可沟通 · 全岛组屋、公寓与有地住宅”。两点在常见问题和页脚里都已写明。
   - 新的情境区块末尾再放一次这两个按钮。
3. **服务区块改成大图拼贴（bento）**
   - 灯光卡占两列两行，用客厅渲染图。
   - 窗帘用观影场景，门锁与安防用大门特写。
   - 空调、控制方式、能耗用深色线稿卡。
   - 手机上两列，灯光卡和能耗卡横跨整行。
4. **新增“按情境”区块**：三张竖向大图卡（出门在外、睡前与夜间、几代同住），链到上一轮新建的三个场景页，带编号，文字压在渐变上。
5. **深浅分区交替**：

   | 区块 | 底色 |
   |---|---|
   | 首屏 | 深 |
   | 服务 | 浅 |
   | 样板间 | 深（从紧贴首屏移到服务区块之后） |
   | 情境 | 浅灰 |
   | 产品与定制 | 浅 |
   | 住宅类型 | 浅灰 |
   | 流程 | 浅 |
   | 平台 | 深 |
   | 常见问题 / 小问卷 | 浅 |
   | 联系 | 浅灰 |
   | 页脚 | 深 |

6. **滚动动效和微交互**（只用 CSS，开启“减少动态效果”时全部关闭）：
   - 大图卡进入视口时，图片从 108% 缓慢收回原尺寸。
   - 悬停时，卡片上浮，图片轻微放大。
   - 按钮里的箭头在悬停时前移。
   - 首屏不做入场动画：标题和渲染图是最大内容元素（LCP）的候选，动画会推迟首屏显示。
